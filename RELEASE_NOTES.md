# Paper Noter v0.7.5

## 中文

Paper Noter v0.7.5 改进了“理解图片”入口在不同语言和浏览器尺寸下的布局表现。

主要更新：

- 修复英文 “Understand image” 文案超出按钮边界的问题。
- 扩展按钮会根据可用空间稳定换行，并保持图标与文字居中。
- 同步调整桌面端与窄屏端的左侧阅读留白，避免按钮遮挡 PDF 内容。

Full 安装包包含完整 CMap、标准字体回退、WASM 与 ICC 资源。

## English

Paper Noter v0.7.5 improves the image-understanding control across interface languages and browser sizes.

Highlights:

- Fixes the English “Understand image” label overflowing its button.
- Keeps the icon and wrapped label centered within the available space.
- Reserves matching reader space on desktop and narrow screens so the control does not cover PDF content.

The Full package includes complete CMaps, standard-font fallbacks, WASM, and ICC resources.
